# Lazer Hall — SMAS-ліфтинг −40% (рекламний ролик)

Вертикальне відео 1080×1920, 30 fps, H.264 + AAC, ~30,5 с. Композиція Remotion `LazerHallSmas40`.

## Структура

| Шлях | Що це |
|---|---|
| `src/lazerhall/cues.json` | Єдиний таймлайн: межі сцен, моменти появи тексту, список звукових ефектів |
| `src/lazerhall/scenes/*.tsx` | Сцени: хук, −40%, HIFU 7D, переваги, до/після, дві пропозиції, CTA, фінал |
| `src/lazerhall/components.tsx`, `theme.ts` | Кліпи з push-in, плашки, анімації тексту, кольори та шрифти Inter |
| `scripts/lazerhall/prepare_clips.sh` | Перекодування iPhone HEVC `.MOV` у вертикальні H.264 `clip-XXXX.mp4` |
| `scripts/lazerhall/make_audio.py` | Синтез оригінальної музики та звукових ефектів (без сторонніх семплів) |
| `scripts/lazerhall/build.sh` | Повне збирання: аудіо → рендер → зведення −14 LUFS → фінальні MP4 |
| `output/lazerhall/` | Готові файли |

## Перезбирання

```bash
npm ci
pip install numpy scipy
scripts/lazerhall/prepare_clips.sh /шлях/до/IMG_*.MOV   # лише якщо змінились вихідні відео
scripts/lazerhall/build.sh
```

Щоб змінити момент появи тексту, змініть значення в `cues.json`: анімація і відповідний звуковий ефект зсунуться разом.
Перегляд у Studio: `npm run dev` → композиція `LazerHallSmas40`.
