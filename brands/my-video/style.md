# My Video — дизайн-система персонального бренду

> **Актуальний напрямок (правки клієнта після першої версії):**
> - Типографіка без плашок: великий шоколадний Inter прямо на стіні, вирівнювання зліва, слова з'являються по черзі.
>   Плашки лише для ключових слів: квадратний butter-тег з тонким шоколадним контуром 1,5 px
>   (BLACK FRIDAY, «листопада», «консультація», «індивідуальне менторство»).
> - Типографіка — Inter; субтитри — Gilroy (Medium, ключові слова ExtraBold ×1,3), letter-spacing −5 %.
>   Playfair і Sloop у роликах не використовуємо.
> - Субтитри зліва (x≈64, y≈1110), 60 px, просто білі — без обводки, тіні й плашок;
>   фрази по 1–2 слова, максимум два рядки одночасно, потім зникають і з'являється наступна фраза.
> - Плани лише широкий → середньо-широкий (до ×1.23): видно крісло, позу й ноутбук. Без крупних планів.
> - Колір майже оригінальний (лише легкий roll-off світлих); червоний на ноутбуці не чіпати.
>
> Нижче — початкова система; де вона суперечить цим пунктам, діють пункти вище.

Файли: `brands/my-video/assets/` (шрифти, аудіо, відео). План поточного ролика: `plan-black-friday.md`.

## Формат

- 1080×1920 (9:16), 30 FPS, MP4 H.264, аудіо AAC; голос ≈ −14 LUFS.
- Безпечна зона Instagram: нічого важливого вище y≈200 і нижче y≈1500; праворуч ≥140 px вільно (кнопки Reels).
- Заголовки та акценти — верхня третина кадру (y≈240–640), над обличчям.
- Субтитри — y≈1180–1300, тобто на рівні грудей/рук (так у референсах), по центру, ширина ≤ 820 px.

## Кольори

| Токен | HEX | Де |
|---|---|---|
| Chocolate | `#462B21` | текст на світлих плашках, фон акцентних плашок, обводка субтитрів |
| Beige | `#EADCC8` | плашки другого рівня, текст на шоколаді, фон вставок |
| Butter | `#F6E7A8` | головні акценти: BLACK FRIDAY, відсотки знижок, дати |
| White | `#FFFFFF` | лише субтитри (з тонкою шоколадною обводкою) |

Інших яскравих кольорів не використовуємо.

## Шрифти

| Файл | Роль |
|---|---|
| Inter ExtraBold | BLACK FRIDAY, великі відсотки (−50% / −30% / −40%) |
| Inter Bold | заголовки, ключові фрази, назви послуг, CTA |
| Inter Medium | субтитри, пояснювальний текст |
| Inter Light (BETA) | тонкі підзаголовки |
| Playfair Display Italic (Google Fonts) | 1–2 елегантні українські слова: «знижки», «саме той момент» |
| Sloop ScriptOne | тільки латинські декоративні слова (кирилиці у шрифті НЕМАЄ) |

Не використовуються: Inter Italic, Playfair Display Bold/Black (у резерві), Sloop ScriptThree.
У Playfair немає ₴ — символ гривні набирати Inter.
Sloop — ніколи не для субтитрів, відсотків, дат, основної інформації, CTA.

## Плашки

- Тільки прямокутні, `border-radius: 0`. Жодних pill-форм і заокруглень.
- Варіанти: Butter + Chocolate текст (головний), Chocolate + Beige/Butter текст, Beige + Chocolate текст.
- Внутрішні поля: 0.18em по вертикалі, 0.35em по горизонталі.
- Не більше двох плашок у кадрі одночасно.

## Субтитри

- Inter Medium, ~44 px, білий, обводка 3 px `#462B21`, ледь помітна тінь.
- 2–4 слова на рядок, максимум 2 рядки; синхрон по словах.
- Без плашок, без жирних слів, без «стрибаючих» анімацій — лише м'який fade 4 кадри.

## Рух

- Поява: fade + зсув 16–24 px + blur 6→0 px, 10–14 кадрів, easing `cubic-bezier(.2,.8,.2,1)`.
- Плашки «розкриваються» по ширині (clip-path) за 10–12 кадрів, текст — слідом.
- Без flash, shake, glitch, вибухів, bounce.

## Колір відео

Natural cinematic: трохи тепліше, м'який контраст, highlights −10–15%, shadows +5–10%, насиченість −5–10%,
корекція тону шкіри (менше жовтизни/сірості) без розмиття текстури.
